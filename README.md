

# 🌊 ONG Coração D'Água: Plataforma Web Front-End

Este projeto é o desenvolvimento Front-End completo para a ONG Coração D'Água, focada na proteção da vida marinha e na limpeza dos oceanos. Ele serve como aplicação prática dos fundamentos de HTML5, CSS3 e JavaScript, seguindo as melhores práticas de desenvolvimento web profissional.

#  Objetivos do Projeto

O objetivo principal foi criar uma presença digital profissional e funcional para a ONG, focando na transparência e na conversão de usuários (voluntários e doadores).

#  Estrutura e Tecnologias

O projeto é baseado em uma arquitetura Front-End pura, focada em performance e manutenção.

# Tecnologias

    HTML5

    CSS3

    JavaScript (ES6)

    Fontes: Montserrat (Títulos) e Poppins (Corpo de Texto)

 # Páginas desenvolvidas

     index.html - Página Inicial

     quem-somos.html - Institucional, Valores, e Transparência

     projetos.html - Apresentação dos projetos da ONG

     cadastro.html - Formulário de Inscrição para Voluntários

     doacao.html - Formulário para doação
